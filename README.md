# Fern-and-Petals-Sales-Dashboard-
## Project Overview
This project is a sales dashboard created using Microsoft Excel. 
It analyzes sales data of Ferns and Petals to understand business performance and customer behavior.

## Key Insights
- Total Orders: 1000
- Total Revenue: ₹35,20,984
- Average Delivery Time: 5.53 hours
- Average Customer Spend: ₹3,520

## Dashboard Analysis
The dashboard includes:

- Revenue by Occasions
- Revenue by Category
- Revenue by Hour
- Revenue by Months
- Top 5 Products by Revenue
- Top 10 Cities by Orders

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## Purpose
To analyze sales performance and identify trends in customer purchasing behavior.
